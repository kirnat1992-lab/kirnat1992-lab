### 🚀 Featured project

**[LNG Event Classifier →](https://github.com/kirnat1992-lab/lng-event-classifier)**  
A reproducible NLP baseline for classifying LNG shipping-event descriptions into 10 categories using **TF-IDF + logistic regression**. Includes a documented dataset, evaluation metrics, error analysis, automated tests, and GitHub Actions CI.

> The current dataset is **synthetic**; reported model metrics are demonstration results, not validated performance on real-world shipping reports.
